# 🚗 Car-booking MERN Stack Car Booking Website

একটি সম্পূর্ণ Car Booking Website যা MERN Stack ব্যবহার করে তৈরি করা হয়েছে। এখানে user authentication, car booking system, admin dashboard, payment integration এবং responsive UI এর মতো modern features ব্যবহার করা হয়েছে।

---

# 🚀 Features

## 👤 User Features

* User Registration & Login
* JWT Authentication
* Browse Available Cars
* Car Details Page
* Search & Filter Cars
* Book a Car
* Online Payment System
* Booking History
* User Dashboard
* Responsive Design

## 🛠️ Admin Features

* Add New Cars
* Update Car Information
* Delete Cars
* Manage Bookings
* Manage Users
* Dashboard Analytics

---

# 🛠️ Technology Stack

## Frontend

* Redux Toolkit / Context API

## Backend

* Node.js


---

```bash
cd your-repo-name
```

---

# 📦 Backend Setup

## Install Backend Dependencies

```bash
cd server
npm install
```

## Create .env File

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

## Run Backend Server

```bash
npm run dev
```

---

# 💻 Frontend Setup

## Install Frontend Dependencies

```bash

```

## Run Frontend

# 🔄 API Endpoints

## Auth Routes

```bash

```

## Car Routes

```bash
GET /api/cars
GET /api/cars/:id
POST /api/cars
PUT /api/cars/:id
DELETE /api/cars/:id
```

## Booking Routes

```bash
POST /api/bookings
GET /api/bookings
DELETE /api/bookings/:id
```
